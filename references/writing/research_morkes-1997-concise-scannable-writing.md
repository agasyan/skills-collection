# Concise, SCANNABLE, and Objective: How to Write for the Web
John Morkes, Jakob Nielsen (1997). Nielsen Norman Group (SunSoft usability lab studies). https://www.nngroup.com/articles/concise-scannable-and-objective-how-to-write-for-the-web/
Type: research · Read: 2026-10-06

## What they did
- Three lab studies at SunSoft, Menlo Park, summer 1997: 81 users in total.
- Study 2 (19 users) observed how people read web text; Study 3 (51 users) tested 5 versions of one 7-page site, between subjects.
- Versions: promotional control, concise (about half the words), scannable (bullets, bold keywords, more headings, shorter sections), objective (no hype), and all three combined.

## Findings
- **People scan first.** 15 of 19 users always scanned unfamiliar text before reading; 3 read word by word.
- **Half the words, faster and better recall.** Concise: task time 359 → 209 s, memory 41% → 65%, overall usability +58%.
- **Scannable layout works.** Scannable: task time 229 s, error score 0.82 → 0.30, memory 55%, usability +47%.
- **Effects stack.** Combined: task time 149 s, error score 0.10, memory 67%, usability +124% (geometric mean of 5 normalised measures).
- **Hype costs.** Removing promotional language alone gave +27%.
- **Conclusions first.** 8 users said summaries and conclusions up front save time.

## For writing docs
- Cut to about half the words: concision gave the largest single gain (+58%).
- Use headings, bullets, and bold keywords so readers can scan (+47%).
- Lead with the conclusion, then details.
- Drop promotional and self-praising language (+27%).
- Write headings that name the content, and keep one idea per paragraph, keyword first (Nielsen's companion article: https://www.nngroup.com/articles/how-users-read-on-the-web/).
