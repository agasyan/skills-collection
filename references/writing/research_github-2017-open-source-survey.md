# Open Source Survey 2017
GitHub (2017). GitHub survey designed with input from researchers at Carnegie Mellon, Drexel, Wikimedia, and Mozilla. https://opensourcesurvey.org/2017/
Type: research · Read: 2026-10-06

## What they did
- Surveyed 5,500 people randomly sampled from activity on 3,800+ open source repositories on GitHub, plus 500+ from other platforms (results cover the random sample).
- 50+ questions, fielded in English, Spanish, Chinese, Japanese, and Russian; data released under CC0.

## Findings
- **Bad docs are the top problem.** 93% had met incomplete or outdated documentation (n = 3,371), ahead of unresponsiveness (78%) and dismissive responses (56%).
- **Few fix it.** 60% of contributors rarely or never contribute to documentation.
- **Licenses matter most.** 64% call a license very important when choosing a project to use; 67% when choosing one to contribute to.
- **Process docs welcome newcomers.** Contributing guides and codes of conduct are valued more by underrepresented groups, such as women.
- **Many readers aren't fluent.** Nearly a quarter read and write English less than "very well".

## For writing docs
- Fix docs first: missing or confusing docs are the problem users hit most.
- Write clear, plain English for the quarter of readers who are not fluent.
- Ship a license, a contributing guide, and a code of conduct with every project.
