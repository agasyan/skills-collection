# Progressive Disclosure
Jakob Nielsen (2006). Nielsen Norman Group. https://www.nngroup.com/articles/progressive-disclosure/
Type: research · Read: 2026-10-06
Evidence: none cited

## What it says
- Show a few of the most important options first and move advanced or rarely used features to a secondary screen that users open on request.

## Findings
- **Three usability gains.** It improves 3 of usability's 5 components: learnability, efficiency of use, and error rate.
- **Novices and experts both win.** Novices spend attention only on features likely to matter; experts skip scanning past features they rarely use.
- **Get the split right.** Everything users frequently need goes up front and nothing confusing does. Task analysis and field studies set the split for new designs; frequency-of-use statistics set it for existing ones.
- **Make the next level obvious.** The control that reveals more must be visible and labeled so users know what they will find, as in the print dialog's advanced-options button.
- **Two levels maximum.** "Designs that go beyond 2 disclosure levels typically have low usability because users often get lost."
- **Staged is different.** Wizards split by task order and are "problematic when the steps are interdependent and users must alternate between them."

## For internal systems
- Build the first screen from the columns and actions people actually use in today's sheets and email threads; put the rest behind one clearly labeled "More" level.
- Use a wizard only for linear one-off tasks such as a first import; keep everyday editing on one screen where any field can be revisited.
- After launch, use usage counts to promote or demote features between the two levels.
