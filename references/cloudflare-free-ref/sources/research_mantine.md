Type: docs · Read: 2026-10-06

## What it says
- **Scope:** "120+ customizable components and 70 hooks", plus extensions for forms (`@mantine/form`), dates, notifications, spotlight (command palette), rich text, and charts.
- **Styling:** "built with native CSS"; CSS modules and a PostCSS preset; no Tailwind needed.
- **Aim:** "Build fully functional accessible web applications faster than ever."

## For an internal system
- Pick it over shadcn when you want everything ready-made (date pickers, notifications, forms) instead of assembling pieces.
- Use one kit per app; don't mix Mantine and shadcn styling.
