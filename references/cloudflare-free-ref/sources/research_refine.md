## What it says
- **What it is:** "a React meta-framework for CRUD-heavy web applications", for "internal tools, admin panels, dashboards and B2B apps".
- **Headless:** it decouples business logic from UI and routing.
- **UI integrations:** Ant Design, Material UI, Mantine, Chakra UI, and shadcn/ui, or custom Tailwind.
- **Built in:** authentication, access control, routing, data fetching and state, forms and tables, i18n, real-time, audit logs, and backend connectors (REST, GraphQL, Supabase, Strapi).

## For an internal system
- Reach for it when the system is mostly list, create, edit, and show screens; it saves building auth, access control, and CRUD plumbing.
- Point its REST data provider at the Hono API under `/api/*`.
