## What it says
- **Not a package:** "This is not a component library. It is how you build your component library." You copy component code into your project and own it.
- **Principles:** Open Code, Composition, Distribution, Beautiful Defaults, AI-Ready ("Open code for LLMs to read, understand, and improve").
- **Data table is a guide, not a component:** "Powerful table and datagrids built using TanStack Table." It walks through row actions, pagination, sorting, filtering, column visibility, and row selection.
- **Why a guide:** "Every data table or datagrid I've created has been unique."

## For an internal system
- Use it as the default kit: Tailwind styling, code you can change, nothing locked in a dependency.
- Build tables from its TanStack Table guide; row selection gives you the batch bar.
- AI tools can read and edit the copied code directly, which suits a budget-limited Claude.
