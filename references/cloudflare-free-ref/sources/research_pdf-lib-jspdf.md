## What it says
- **pdf-lib:** "Create and modify PDF documents in any JavaScript environment"; fills existing form fields; adds, removes, splits, and merges pages; "no native dependencies", runs in browsers, Node, Deno, and React Native. It draws by API; it does not render HTML.
- **pdf-lib activity:** no push since July 2024.
- **jsPDF:** "Client-side JavaScript PDF generation for everyone."

## For an internal system
- Use pdf-lib only to fill an existing PDF form (an official form you must reproduce exactly).
- Prefer react-pdf for documents you design yourself; jsPDF draws at a lower level.
